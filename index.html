常见问题

卡密怎么激活？

打开软件 → 侧边栏"激活 PRO" → 输入卡密 → 点激活即可。支持向上升级，不支持降级。

AI 答题收费吗？

内置 AI 免费用户每天 3 次，PRO 用户每天 100 次。也可以自备 API Key 无限使用，完全免费。

支持哪些系统？

目前只支持 Windows 10 / 11 (x64)，Mac 和 Linux 版本暂未发布。

数据会上传服务器吗？

问卷答案、被踢记录等可选上传用于共享。AI Key、人设等敏感内容全部本地存储，不上传服务器。

被误封了怎么办？

使用软件内置的"邮件助手"生成申诉邮件，通过内置浏览器登录后发送给官方客服，配合 FAQ 文档的模板效果更好。

怎么反馈 Bug 或建议？

打开软件 → 侧边栏"用户反馈" → 跳转 GitHub Issues 提交，也可以在投票榜给其他建议点 👍。提交后会自动收到通知。

换电脑后卡密能转移吗？

每张卡密最多绑定 2 台设备，换设备请联系 admin@moonbazaar.de5.net 申请解绑。
